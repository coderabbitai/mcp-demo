# CodeRabbit MCP Demo Todo

A small CRUD todo list demo built with React, TypeScript, and Vite.

## Features

- Create todos with inline validation
- Read active, completed, and all todos
- Update todo text inline
- Mark todos complete or active
- Delete individual todos
- Clear completed todos
- Persist todos in `localStorage`

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run typecheck
npm test
npm run build
```
